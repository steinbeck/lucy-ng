<objective>
Fix the real, verified Phase-101 reader defect that blocks COSY -- a named,
required experiment for this phase -- and commit the homonuclear/HMBC/NOESY
JCAMP fixtures every downstream Phase-102 test needs.

`readers/jcamp.py::_resolve_dim()` currently raises
`ValueError: Ambiguous nucleus '1H' appears 2 times ...` for any homonuclear
2D file, because it disambiguates dimensions by unique nucleus match. Real
`C20H32O2_COSY.dx` and `C20H32O2_NOESY.dx` both carry `$NUC1 = ['<1H>','<1H>']`
(verified by direct inspection). `JcampReader.read_2d()` therefore raises
before `bridge_peak_pick()` is ever reached, so the Phase-102 CLI cannot
produce COSY output at all.

Purpose: this is the phase's highest-risk task and must land before the CLI
wiring is built around it (102-RESEARCH.md Pitfall 1 / Open Question 1).
`src/lucy_ng/readers/jcamp.py` is NOT in the byte-unchanged protected set
(that set is `PeakPicker2D`, the 1D picker, `nus/qc.py`, `nus/bridge.py`,
`cli/pick.py`, `case.md`, and the 5 agent files), so fixing it is in remit.

Output: three new committed trimmed `.dx` fixtures, a positional-fallback
`_resolve_dim`, and a test class that proves the fix against committed
ground truth rather than against "it doesn't raise any more".
</objective>
