| Boundary | Description |
|----------|-------------|
| browser (localhost) → GET /api/spectra/1d/* | Read-only image endpoint; no request body, no query beyond the cache-bust `?t=`. |

| raw Bruker files at manifest path → nmrglue/matplotlib | Local filesystem read of the path the manifest names. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
