  <name>Task 1: Manual browser check — real 2D contours, reversed axes, cross-peak overlay, HMBC flag colours, COSY diagonal, unavailable states</name>
  <what-built>
    The 2D Spectra tab now renders three real Bruker 2D contour plots (HSQC, HMBC, COSY) as
    server-side matplotlib PNGs, decimated to ≤512×512 with geometric MAD-threshold contour levels
    in a single muted grey, with the picked cross-peaks from `analysis/peaks/{hsqc,hmbc,cosy}.json`
    overlaid as open circles — HSQC/COSY in the accent colour, HMBC colour-coded by flag
    (ok=green / potential_4J=amber / 1J_artifact=grey) with a 3-line flag legend, plus a thin grey
    COSY diagonal. Both ppm axes are reversed on every plot. Each route degrades independently to a
    locked "unavailable" placeholder image at HTTP 200 — never a 500, never a broken-image icon. A
    per-source mtime PNG cache prevents re-rendering on the ~3 s poll when the data is unchanged.
  </what-built>
  <how-to-verify>
    1. Build a manifest-backed dashboard against the REAL CASE1 data. Create a temp `analysis/` dir,
       write `analysis/.run_manifest.json` = `{"bruker_data_dir": "<abs path to .../active-lucy-ng-testprojects/CASE1>", "formula": "C13H18O2"}`,
       add schema-matching `analysis/peaks/{hsqc,hmbc,cosy}.json` (reuse the Wave-0 fixture output or a
       recent CASE1 run's peaks), then `lucy webview serve <that analysis dir>` (note the printed URL).
       Alternatively open a live/recent CASE1 run whose `case.md` already wrote the manifest.
    2. Open the printed URL, click the "2D Spectra" tab. Confirm THREE stacked plots (HSQC, HMBC, COSY),
       each a real contour plot with visible contour rings — NOT empty axes and NOT a stick/scatter-only plot.
    3. Axis direction (SC1): on HSQC confirm BOTH axes are reversed — the aromatic region sits TOP-LEFT
       (δH ~7 ppm on the left of the x-axis, δC ~130 ppm near the top of the y-axis); aliphatic peaks toward
       bottom-right. x-axis labelled `δH (ppm)`, y-axis `δC (ppm)`.
    4. Cross-peak overlay (D-05): confirm the picked cross-peaks appear as OPEN CIRCLES (rings, not filled dots)
       sitting ON real contour signal — a marker floating in empty space would flag a mis-pick (the whole QC point).
    5. HMBC flag colours (SC2/D-06): on the HMBC plot confirm markers are colour-coded — green (`ok`),
       amber (`potential_4J`), grey (`1J_artifact`) — matching the Tables-tab HMBC row colours, plus the small
       3-line flag legend in the top-right corner.
    6. COSY (D-07): confirm a thin grey diagonal line (F1=F2) runs corner-to-corner, with open-circle
       cross-peaks off the diagonal; both axes labelled `δH (ppm)` and reversed.
    7. Stability (SC3/SC4): leave the tab open ~30 s through several ~3 s polls; confirm the plots do NOT
       visibly flicker/redraw on every poll (the mtime cache serves unchanged renders) and the browser
       console shows no uncaught exceptions.
    8. Degradation checks (SP-02) — point `lucy webview serve` at an EMPTY dir (no manifest): confirm each of
       the three 2D `<img>` shows the locked "Waiting for a live CASE run — spectra will appear once analysis
       starts." placeholder IMAGE (a rendered chart with centered grey text), NOT a broken-image icon and NOT an
       error banner. Then point at a manifest whose `bruker_data_dir` is a bogus path: confirm the locked
       "Raw Bruker data not found at the recorded path." placeholder on all three. Confirm each plot degrades
       INDEPENDENTLY (D-10).
  </how-to-verify>
