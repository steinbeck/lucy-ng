## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-104-09 | Spoofing | DatabaseFinder new search names | accept | Only the filename set widens. The search roots stay the same user-owned directories, plus the `ailsa` sibling of the existing `lucy-ng` checkout dir. The new name gets no new untrusted input source or privilege. |
| T-104-10 | Tampering | `database download` zip extraction | accept | Unchanged pre-existing mitigation: only members ending in `.db` and not under `__MACOSX` are extracted, via `shutil.copyfileobj` to a fixed output path (no `extractall`, no zip-slip). |
| T-104-11 | Denial of service | `download --force` on legacy-only install | mitigate | `resolve_default_derep_path()` returns the existing legacy file, so `--force` overwrites in place instead of writing a second ~4 GB copy under the new name. |
</threat_model>
