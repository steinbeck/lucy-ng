- PKG-03 on the real PATH. `/opt/miniconda3/bin/lucy` is an editable lucy-ng install whose script does `from lucy_ng.cli import cli`, and it has been broken since Plan 02.

Output: the pyproject/uv.lock packaging fix, a recorded gate result, and a reinstalled global CLI.

Do NOT upload anything. That is Plan 06, behind a human gate (D-02). Do NOT push (D-05).
</objective>
