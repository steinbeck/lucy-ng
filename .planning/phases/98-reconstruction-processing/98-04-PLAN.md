<objective>
Build `nus/postprocess.py`: the TWO nmrPipe processing stages that bracket the SMILE call (SMILE
manual §4/§6.1 requires the direct dimension processed + transposed FIRST), plus the ppm-axis
reversal and 1D-calibration helper.

- `process_direct()` — apodize/ZF/FT/deterministic-phase/baseline the DIRECT (F2) dimension, THEN
  transpose (TP). Its output is SMILE's ACTUAL input (a transposed, F2-processed FID). Runs BEFORE
  `backend.reconstruct_indirect()` (Plan 03 SMILE call).
- `process_indirect()` — post-SMILE INDIRECT (F1) ZF/FT/deterministic-phase, final transpose (TP),
  reversed 1D-calibrated ppm axes. Runs AFTER SMILE.

Each half runs as ONE D-01 subprocess stage (idiomatic NMRPipe internal `|` chaining is allowed
within the stage), with the stage's final output verified by the Plan-02 `run_stage()` wrapper. Phase
is deterministic and CLI-overridable — never a blind auto-phase search (D-02, Pitfall 10).

Purpose: RECON-02 (F2-first processing + transpose before SMILE; reversed, 1D-calibrated ppm axes).
Output: `src/lucy_ng/nus/postprocess.py`.
