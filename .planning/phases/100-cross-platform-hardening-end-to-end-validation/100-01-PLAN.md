## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local process → OS subprocess (`sysctl`, `shutil.which`, NMRPipe tools) | lucy-ng shells out to platform-introspection and backend binaries; command construction must never interpolate untrusted strings into a shell |
| CLI arg (`expdir`, numeric flags) → NusRunner | developer-supplied paths/values reach subprocess argv and filesystem reads |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-100-01 | Tampering | `platform_check.py` sysctl/which subprocess calls | mitigate | Fixed `list[str]` argv only (`["sysctl","-n","sysctl.proc_translated"]`), `capture_output=True, text=True, timeout=10`, wrapped in `try/except (OSError, subprocess.TimeoutExpired)`; never `shell=True`, never a string-interpolated command (ASVS V5, matches existing `smile_plugin_available()`) |
| T-100-02 | Denial of Service | sysctl / backend probe hanging | mitigate | `timeout=10` on every probe; any timeout/OSError resolves to `rosetta_translated=None`, never blocks the CLI |
| T-100-03 | Information Disclosure | diagnose() `"platform"` output in `--format json` | accept | Emits only local arch/OS/interpreter-presence booleans on the developer's own machine — no secrets, no PII, single-user local CLI |
| T-100-SC | Tampering | external NMRPipe/SMILE binary (ibbr.umd.edu) | transfer | No pip/npm/cargo install introduced by this plan (stdlib only — RESEARCH Package Legitimacy Audit: N/A). The backend binary is a manual, developer-performed download documented in Plan 02; out of automation scope per D-01. No package-manager legitimacy checkpoint applies. |
</threat_model>
