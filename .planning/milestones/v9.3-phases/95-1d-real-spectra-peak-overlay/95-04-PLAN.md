  <name>Task 1: Manual browser check — real ¹³C trace, reversed axis, peak overlay, unavailable states</name>
  <what-built>
    The 1D Spectra tab now renders real Bruker 1D traces (¹³C always, ¹H when present) as
    server-side matplotlib PNGs, with the picked peaks from `carbon_signals.json` overlaid as
    vertical markers + ppm/assignment labels on a reversed ppm axis. Every failure mode
    (no manifest, stale raw path, no matching experiment) shows a locked "unavailable"
    placeholder image at HTTP 200 — never a 500 and never a broken-image icon.
  </what-built>
  <how-to-verify>
    1. Build a manifest-backed dashboard against the REAL CASE1 data. Reliable path: create a
       temp `analysis/` dir, write `analysis/.run_manifest.json` =
       `{"bruker_data_dir": "<abs path to .../active-lucy-ng-testprojects/CASE1>", "formula": "C13H18O2"}`,
       and add a schema-matching `analysis/peaks/carbon_signals.json` (or reuse the Wave-0 fixture
       output), then `lucy webview serve <that analysis dir>` (note the printed URL). Alternatively
       open the dashboard on a live/recent CASE1 run whose `case.md` already wrote the manifest.
    2. Open the printed URL, click the "1D Spectra" tab.
    3. ¹³C Spectrum: confirm a REAL continuous line trace (many wiggles/noise floor), NOT a set of
       clean sticks — this is the whole QC point (D-01: no stick fallback).
    4. Axis direction (SC2): confirm the ppm axis is REVERSED — high ppm on the LEFT. The carbonyl
       (~181 ppm) must sit at the far left; the aliphatic CH₃ groups (~14–23 ppm) on the right.
    5. Peak overlay (D-03): confirm thin vertical accent markers (`#0c5460`) sit AT the picked-peak
       ppm positions, each with a ppm label, and an assignment label (e.g. `C=O`) where present —
       and that the markers line up with real peaks in the trace (mis-picks would be visible here).
    6. Verify the DEPT/quaternary sanity check: the carbonyl peak IS present (a DEPT spectrum would
       drop it) — confirming `_select_experiment` picked the standard `zgpg30` ¹³C, not `dept135/90`.
    7. ¹H Spectrum section: confirm it either shows a real ¹H trace (CASE1 has a ¹H experiment) OR
       the locked "No ¹H experiment in this dataset." placeholder — both are valid; it must NOT be a
       broken-image icon.
    8. Degradation checks (SP-02) — point `lucy webview serve` at an EMPTY dir (no manifest): confirm
       the ¹³C `<img>` shows the locked "Waiting for a live CASE run — spectra will appear once analysis
       starts." placeholder image (a rendered chart with centered grey text), NOT a broken-image icon and
       NOT an error banner. Then point at a manifest whose `bruker_data_dir` is a bogus path: confirm the
       locked "Raw Bruker data not found at the recorded path." placeholder. Browser console shows no
       uncaught exceptions.
  </how-to-verify>
